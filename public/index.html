About

SiteRip renders every page in headless Chromium and passively records the entire network conversation via the DevTools Protocol — markup, styles, scripts, images, fonts and API responses. Links are then rewritten to local paths and a service worker is injected, so the archive keeps working fully offline.

  • Real browser renders — the JS-built DOM is captured, not just raw HTML
  • Sitemap + link crawling for complete page coverage
  • SPA routes & captured API calls replay offline via sw.js
Server-side logic (logins, forms, live APIs) can't be archived — no tool can clone a backend.
